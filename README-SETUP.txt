ALFAMART STORE MAP - SUMBAWA BARAT (LEAFLET)

1. Ekstrak ZIP ini ke folder baru.
2. Pastikan index.html, style.css, dan app.js berada dalam folder yang sama.
3. Buka index.html di browser atau jalankan melalui VS Code Live Server.

Peta menggunakan Leaflet dan tile OpenStreetMap standar. Tidak memerlukan Google Maps API Key maupun CARTO API Key.
Koneksi internet diperlukan untuk memuat library Leaflet dan gambar peta.
Jangan menghapus atribusi OpenStreetMap yang tampil pada peta. Penggunaan tile mengikuti kebijakan penggunaan tile OpenStreetMap.
